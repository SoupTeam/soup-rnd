- **Added three opt-in levers for L2L route-preserving MBR on streamed experts (#76).**
  `L2LStep.run(..., mbr_ordered_backward=True)` runs each MBR group's backward in one
  autograd-engine call and still adds every LoRA gradient in micro-batch order (the order of
  group size 1), by building the group's micro-batches from the last to the first in the forward
  and in the recompute; it excludes `mbr_split_backward`. `ExpertBufferPool.async_lease` (packed
  transfer on CUDA) ends an expert lease without `torch.cuda.synchronize`, so the host prepares
  the next expert while the card computes; its only host wait is for the copy that reads the
  pinned staging region, and a failing lease keeps the full wait. `StreamedExperts.fast_row_gather`
  gathers a visit's rows and route weights with `index_select` and an `index_add_` backward
  instead of the sorted `index_put_`, which is exact because a token reaches an expert once.
  None of them has a config field or CLI flag, none changes a default path, and none changes a
  bit of the loss or of any gradient (CPU tests; CUDA tests for the lease). See
  [`docs/expert-forward.md`](docs/expert-forward.md) and
  [`docs/performance-and-quantization.md`](docs/performance-and-quantization.md).
