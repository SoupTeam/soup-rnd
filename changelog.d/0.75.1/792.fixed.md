- **Fast-LoRA correctness and evidence (D2; upstream tracker #792).** The NF4
  single-projection backward unpacks saved tensors once so non-reentrant
  checkpointing can recompute it safely. QKV backward skips frozen-base GEMMs
  and dequantization when no input gradient is requested, while preserving all
  trainable adapter gradients. Unused QKV outputs now leave adapter gradients
  as None, preserving optimizer weight-decay semantics. The shared-input cache
  refuses stale values after execution-context, adapter or tensor-state changes.
  Heterogeneous QKV/MLP adapter dtypes delegate to PEFT rather than failing
  inside a promoted shared-A GEMM. Regression tests cover
  nested NF4 state, partial adapters and the corresponding failure controls.
  Mixed-precision backward preserves adapter input-gradient cast boundaries,
  SiLU intermediate rounding and PEFT scaling/addition seams. A verified canonical
  low-precision Llama/PEFT scope can select reference-order QKV/MLP arithmetic
  with separate projection GEMMs; unsupported calls retain legacy arithmetic
  without claiming that scope. Cold metadata initialization publishes readiness
  last, and cast eligibility verifies the bound receiver. The selected arithmetic
  is observable independently of the custom Function name; no universal
  bit-exactness or fusion speedup is implied.
  A separate SYNTHETIC evidence harness records forward/backward parity,
  float64 gradcheck, a 50-step loss curve and single-layer ABBA timing in JSON/CSV.
  CPU timings are debug-only; no CUDA or end-to-end multiplier is claimed by the
  existence of the harness, and failed loss-curve gates are retained.
