- **G3: direct NVMe-to-GPU reads measured on Windows with DirectStorage; Soup's unbuffered pinned-staging path stays faster (#32).** On an RTX 4060 laptop (Windows 11, GIGABYTE AORUS Gen4 NVMe), DirectStorage 1.3.0 delivered a 1 GiB file correctly into a D3D12 buffer imported into CUDA in every run, at 2.89 GB/s against 3.53 GB/s for the #974-style unbuffered read into pinned staging plus host-to-device copy (5 interleaved blocks, 95% interval of the difference -0.675 to -0.616 GB/s). The DirectStorage route through host memory is not attributed and no host-RAM saving is claimed. On Linux, eight rented GPU hosts could not run GPUDirect Storage natively (environment-blocked), and NVIDIA documents GeForce as compatibility-mode only. The frozen probes, protocols and evidence are under `benchmarks/g3/`; the Windows report is `benchmarks/g3/reports/20261104_directstorage/REPORT.md`.
