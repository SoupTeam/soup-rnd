- **`training.l2l` accepts `lora.dropout` and `attention_dropout` above 0 (#31).**
  Each layer call seeds the generator from the training seed, the optimizer step,
  the micro-batch and the layer, so the layer-major order does not change a mask.
  At dropout above 0 the reference is gradient accumulation with the same state
  function, not an unmodified Hugging Face Trainer. A window whose micro-batches
  differ in length is refused at dropout above 0, because padding changes the
  masks. Configs with `l2l: false` are unchanged.
