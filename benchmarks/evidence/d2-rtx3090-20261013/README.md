On PowerShell, concatenate in filename order without interpreting the binary data:

```powershell
$target = [IO.File]::Create((Join-Path (Get-Location) 'd2-rtx3090-20261013-handoff.zip'))
try {
  Get-ChildItem -File 'd2-rtx3090-20261013-handoff.zip.part-*' | Sort-Object Name | ForEach-Object {
    $source = [IO.File]::OpenRead($_.FullName)
    try { $source.CopyTo($target) } finally { $source.Dispose() }
  }
} finally { $target.Dispose() }
Get-FileHash 'd2-rtx3090-20261013-handoff.zip' -Algorithm SHA256
Expand-Archive 'd2-rtx3090-20261013-handoff.zip' -DestinationPath extracted
```
