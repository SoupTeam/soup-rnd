# D1: состояние после подготовки L, 2026-10-16

## Текущий статус: условный BF16 WMMA-кандидат проверен; полный D1 не закрыт

Актуальный результат — [WMMA-отчёт](d1-wmma-result-20261016.md).
Исходник `ba6928e9af116c11d56257cf8d532ec51c3dee17`: явный WMMA backend,
полный FP32-режим BF16-накопления, выровненные training-проекции. Большой
192 MiB recycled buffer, negative control, настоящий streamed decoder
на seq 128/2048 и 3 полных LoRA/SGD-шага проходят точное сравнение.
127 локальных тестов прошли, 13 hardware tests пропущены, Ruff чистый.

Штатный численный режим не покрыт; ускорение не доказано. Короткий экран
наблюдал 4.092/2.857 мс candidate/native и экономию 23.25 MiB allocated memory.
Частоты 1545–1965 MHz дают NO_VERDICT скорости по полному правилу.
Production не изменён. Пакет пригоден для research review с этими ограничениями.

Текущий снимок D1: $8.168/$10, остаток $1.832. Все короткие kernel-пробы вместе
$0.107. Машины 56220625, 56221386, 56223817 удалены, отсутствие подтверждено;
попытка недоступного offer не создала аренду. Новых расходов автоматически
не начинать после завершения этих ограниченных проверок. Старый K-пакет и ZIP
не изменялись. Ниже сохранено прежнее состояние как история, не текущий вердикт.

### Первый новый kernel-кандидат проверен и отклонён

См. [результат короткого CUDA-теста](d1-kernel-screen-result-20261016.md).
Новый fused forward/dX реализован в исследовательском коде. На RTX 3090
распаковка совпала точно; forward и dX — нет. Кандидат не прошёл bit-exact
gate, production не изменён, D1 полностью не закрыт. Следующие проверки
остановлены при первом несовпадении, обучение/скорость не запускались.

CUDA source: `6ead078a2c375fe3aa31f52beab4703ccfb9dc5b`. Сырые тензоры и
CPU-аудит сохранены. Локально 125 passed, 13 hardware skips, Ruff чистый.
Проверяющему передавать прототип с явным FAIL, а не объявлять его готовым kernel.

Увеличение общего лимита до $15 пользователь отклонил. Затем отдельно разрешил
до $0.25 из остатка на ОДИН короткий CUDA-тест. Этот тест завершён; по текущему
снимку потрачено $0.023, суммарно D1 $8.084 из $10. Машина 56216532 удалена,
отсутствие подтверждено. Другие машины аккаунта не трогать. Продолжение платных
экспериментов не считать автоматически разрешённым этим одноразовым тестом.

Потребность следующей итерации: добиться native CUDA bit-exact арифметики
GEMM, затем проверить большие recycled buffers и streamed decoder/LoRA-gradients.
Только после этих gates измерять скорость/VRAM полного шага. Не возобновлять
старую 98-case сетку как замену отсутствующему принятому kernel.

## Что подготовлено

- Отдельный dense-reference интервал после фиксации основных пиков VRAM:
  >=20 вызовов/1 с прогрева, >=200 вызовов/1 с измерения, сырые NVML-данные.
- Повторная проверка сырых данных при построении отчёта: UUID, границы фаз,
  частота SM, лимит мощности, контроллер памяти, длительность и число вызовов.
  Изменение частот >5% или отсутствие данных даёт NO_VERDICT.
- Отдельный режим `--case NAME` для заранее объявленной дополнительной серии.
  Полный индекс по-прежнему отвергает сокращённый план.
- [Применимое решение для Soup](d1-soup-impact-20261016.md) и ссылка на него
  из руководства по streaming. Прирост скорости в production не заявляется.
- Проверки: 113 passed, 13 hardware skips; полный Ruff и `git diff --check`.
  Это CPU-проверки подготовки, не новые CUDA-результаты.

## Деньги и следующий запуск

Подтверждённый снимок расходов D1 — $8.061, прежний согласованный общий лимит
$10, остаток $1.939. Новая D1-машина в рамках этой подготовки не арендована.
Другие машины аккаунта не относятся автоматически к D1 и не должны удаляться
или использоваться этим заданием.

По длительностям K: 17 невалидных случаев — 1.57 ч выполнения свежих процессов;
вся серия — 9.35 ч без подготовки и экспорта. Дополнительная выбранная серия
может занять 3–5 ч с подготовкой, но не восстановит старые reference-окна.
Полная новая серия требует нового измеренного источника, подходящей GPU,
новой проверки корректности и нового бюджета времени на все 98 случаев.

Снимок предложений аренды 2026-10-16: A100 без гарантии clock control от
примерно $0.49/ч; VM RTX 3090 с 130 GB диска примерно $0.3815/ч, сетевой
трафик оплачивается отдельно. Наличие VM не доказывает возможность фиксации
частоты. Старый отказ clock control на A100 нельзя считать исправленным.

Для планирования полного повтора: ориентир 10–16 ч и $4–6 новых расходов
при подходящей недорогой карте, с проверкой этого прогноза по первому случаю.
Это оценка, не измеренная длительность новой GPU. Общий лимит около $15 либо
GPU команды дали бы запас; увеличение прежнего лимита ещё НЕ согласовано.
В пределах $10 нельзя обещать полное закрытие D1. До решения о ресурсах
не запускать платную полную сетку или старые контроллеры удалённой машины.

При доступе к GPU сначала проверить фиксацию частот и отсутствие посторонних
CUDA-процессов. После этого заморозить новый план/исходники, выполнить оба
CUDA correctness fixture и GPU regressions, затем ABBA-серии. Ранний случай
с новым нарушением частот останавливает дальнейшие расходы; исходные ошибки
сохраняются. Для платной машины обязательны отдельные границы измерений,
экспорта и удаления, рассчитанные на остаток согласованного лимита.
