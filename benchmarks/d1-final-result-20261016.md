# D1: итог для research review

**Проверенная польза для Soup — уменьшение VRAM полного шага. Подтверждённого
ускорения нет.** Реализован ограниченный checkpoint-safe BF16 NF4 kernel;
исследовательский пакет готов к проверке тимлидом. Полную приёмку D1 нельзя
отметить пройденной: formal speed verdict остаётся NO_VERDICT, универсальная
поддержка форм, типов и GPU не заявляется. Production автоматически не переключён.

## Что сдаётся

CUDA WMMA kernel распаковывает NF4 в shared memory, не создавая полный BF16 вес.
Все шесть тензоров frozen state проходят через `save_for_backward`; повторное
вычисление восстанавливает правильный recycled buffer. На проверенной большой
форме dX воспроизводит штатное cuBLAS split-K округление; готовый fused forward
bitsandbytes переиспользуется. Глобальная BF16-арифметика Torch не меняется.

Реализация и API: `benchmarks/harness/d1_wmma_nf4.py`, `d1_fused_nf4.py`,
явный backend `wmma_native64`. Разрешены только ранее проверенные descriptors.
Финальный harness `d1_final_f1.py` сохраняет обычный Soup dispatch для остальных
проекций; отдельный регрессионный тест защищает этот fallback.

Основной результат предыдущего этапа и большой negative control:
[штатная арифметика](d1-native-result-20261016.md). Новая проверка ниже дополняет
их большим decoder и исправляет интерпретацию маленького пилота скорости.

## Полный шаг через Soup на большем decoder

Синтетический Llama decoder: hidden4096, intermediate4096, четыре слоя,
32 attention heads / 8 KV heads, vocab64, seq128, nested NF4, BF16,
два RAM-backed streaming slots, LoRA q/v rank4 alpha8, dropout0, SGD lr0.001.
Это shape fixture с настоящим runtime Soup, а не pretrained 7B/8B-модель.
Кандидат заменяет только покрытые проекции; k/v с другой формой сохраняют native путь.

| Peak VRAM полного шага | Native | Кандидат | Разница |
|---|---:|---:|---:|
| Allocated | 371988992 B | 207362048 B | **−164626944 B = −157 MiB** |
| Reserved | 381681664 B | 234881024 B | **−146800640 B = −140 MiB** |

В обоих A-процессах и обоих B-процессах соответствующие peaks воспроизвелись.
Измерение сделано после warmup, до выделения dense GEMM reference. Это полные
model-step peaks; прежние −23.25 MiB одной LoRA-проекции не подменяют эту строку.
Memory-controller utilization во время шага: native 9–12%, кандидат 3–4%.
Эти проценты относятся только к данной карте и данному fixture.

Время: описательная медиана двух A — 92.048 мс, двух B — 92.900 мс.
Один полный fresh-process ABBA блок выполнен, по 20 warmup / 200 timed SGD-шагов
в каждом процессе. Power/suspend/foreign-read checks и GPU peer lifecycle чистые.
Однако SM в primary/reference вместе менялась 1320–2040 MHz; разрешения на lock
не было. Блок отклонён по заранее записанному правилу, остальные четыре не запущены.
**Нельзя ни заявлять ускорение, ни доказывать регрессию по этим временам.**
Same-session dense GEMM, raw step timings и вся телеметрия приложены.

Предыдущие 9.6% на hidden64 и 23.7% на одной проекции остаются маленькими пилотами.
Большой fixture не подтвердил их как ускорение продукта. Итоговый product claim
этого исследования — измеренная экономия памяти на указанном полном шаге.

## Корректность и воспроизведение

- Три последовательных native/candidate full-step обновления большого decoder:
  logits, loss, все 16 LoRA-градиентов и 16 обновлённых параметров exact.
- Дополнительно три обновления против **непатченного resident NF4**: все те же
  34 величины exact. CPU replay CUDA-снимков подтвердил каждую; градиенты ненулевые.
- Ранее: packed buffer 192 MiB, два вызова checkpoint после перезаписи весов/scales,
  exact forward/dX и ожидаемо отличающийся конечный plain-ctx контроль в том же процессе.
- На физической RTX 3090 прошли **12 GPU-регрессий #842/#968**, 17 deselected.
- Локальная D1-регрессия: **132 passed, 13 hardware skips**; после небольших правок
  запускателя дополнительно 29 focused checks прошли. Полный Ruff и diff-check чистые.

Source SHA target correctness: `2c53b0a5` (полный SHA в manifest/audit);
исправленного ABBA driver: `28c4415f`. Арифметические зависимости одинаковы.
Перед запуском зафиксированы [правило](d1-final-f1-rule-20261016.md) и ограничение
первым невалидным блоком. Ни threshold, ни эталон после результатов не менялись.

Последняя попытка отдельного A100 cohort не дошла до CUDA: Docker image не
загрузился за десятиминутное короткое окно. Аренда удалена; результат не смешан
с RTX. Дополнительный служебный dispatch probe после архивирования не имеет
полного экспортированного JSON и в приёмку не засчитывается.

## Вердикт и передача

Пакет сдаётся **на research review** с конкретной памятью, реализацией и исходными
данными. Для Soup это кандидат на уменьшение памяти streaming-шагов, а не обещание
более быстрого обучения. Если цель карточки требует именно готового production
ускорения, этот критерий остаётся открытым. До проверки ревьюером не включать
backend автоматически и не закрывать исходный #842 как полностью решённый.

Дальнейшие аренды, сетки и длительные тренинги не запущены. Принятие результата
или отдельная доработка универсального backend — решение тимлида после review.

[Manifest](evidence/d1-final-f1-20261016/manifest.json) содержит SHA-256 raw archive,
все JSON/log records и независимый аудит. В `raw-final-f1.tgz` находятся executed
source archives, команды, packages, CUDA-снимки, ошибки запуска и отклонённый ABBA.
Ошибки pytest plugin / повторного создания каталога исправлены до timing; записи
не удалены. Две независимо собранные копии архива совпали с серверным SHA-256.

Обе новые аренды (56230417, 56231757) удалены, отсутствие проверено.
Новые расходы по снимку: **$0.098**, суммарно D1 **$8.354/$10**,
остаток **$1.646**; billing может обновляться. Общий потолок соблюдён.
