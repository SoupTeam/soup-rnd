Статический разбор точных дистрибутивов Liger 0.8.5, Transformers 5.17.0,
TRL 0.29.1: SHA каждого wheel совпал с метаданными PyPI. Пакеты не устанавливались.
Llama-патч по умолчанию включает RoPE, RMSNorm, SwiGLU и FusedLinearCrossEntropy;
обычный cross_entropy выключен. FusedLinearCrossEntropy заменяет
forward LlamaForCausalLM,
и при training+labels использует fused loss без материализации полных logits.
Transformers baseline сначала делает logits.float(), затем обычный CE.
Оба helper используют mean при отсутствии num_items_in_batch; при наличии
считают sum / num_items_in_batch. Поэтому разные знаменатели не установлены.

Soup применяет class patch до загрузки модели, а Transformers Trainer затем
применяет instance patch. Для будущей изоляции конфигурация должна совпадать
на обоих этапах. Выключение флага не отменяет уже сделанный глобальный patch:
каждому варианту нужен новый процесс и явные проверки функций/классов.

Уточнение следующего эксперимента: отдельно Fused-LCE-only и CE-only,
а также RMSNorm-only, RoPE-only, SwiGLU-only, baseline и combined.
CE-only не заменяет Fused-LCE-only в диагностике текущего combined-варианта.
Матрица — проект, не готовый GPU runner и не разрешение на запуск.
Нужны проверки фактических патчей, точного состояния и runtime-путей,
замороженный исходник, лимиты времени/бюджета и отдельный correctness-прогон.

Причина расхождения пока НЕ установлена. Наличие fused path не доказывает
ошибку именно в нём. Исходники проверены по опубликованным pinned wheels;
каждый установленный на удалённом сервере Python-файл отдельно не хэшировался.
GPU-версия и фактические kernels подтверждены исходными receipts/trace.
CPU-разбор не доказывает CUDA-корректность или ускорение.

Воспроизводимость: h2_gradient_diagnostic.py читает два каталога model_probe
и создаёт новый JSON (--reference, --candidate, --output). Файл результата
не перезаписывается. source_review.json содержит URL/версии/SHA исходников,
gradient_geometry.json — SHA входных evidence и геометрию каждого тензора.
