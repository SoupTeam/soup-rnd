# D1 — текст для передачи тимлиду

[PR #16](https://github.com/SoupTeam/soup-rnd/pull/16) содержит checkpoint-safe
fused NF4 kernel без полного промежуточного BF16-веса и исходные проверки.
Production dispatch автоматически не переключён.

На **реальной Mistral-7B-v0.3 в RAM-стриминге Soup**, batch1/seq128, BF16/NF4,
два pageable GPU-буфера, q/v LoRA rank4:

- Allocated: **804.24→740.74 MiB**, −63.5 MiB /**−7.90%**.
- Reserved: **826→794 MiB**, −32 MiB /**−3.87%**.
- Шаг: **1.726→1.730 s**. Это один короткий чистый ABBA-блок (80 timed steps),
  достоверную разницу скорости по нему не устанавливаем.

Три обновления точно совпали с native RAM streaming: logits, loss, все128
adapter tensors и128 градиентов на каждом шаге —774 величины. Градиенты ненулевые,
полные pretrained weights подтверждены upstream SHA. **Качество после долгого
обучения и сверку streaming-пути с unpatched resident NF4 этой7B не проверяли.**
Ни один путь не получил OOM; возможность запустить ранее не помещавшуюся модель не показана.

Отдельно сравнили исходную BF16 и обычную NF4 Mistral7B на16352 held-out
токенах: perplexity **6.602→6.812 (+3.18%)**, меньше лучше. Небольшое ухудшение
есть; идентичное качество заявлять нельзя. Это resident base-model screen без
обучения и без D1 kernel, не дополнительная потеря от нашего kernel.
[Короткий отчёт качества](d1-quant-quality-result-20261019.md).

[Отчёт реальной7B](d1-real7b-result-20261019.md) отделён от
[синтетического F1](d1-vm-f1-result-20261019.md): там пять валидных блоков,
4000 шагов, −157/140 MiB и замедление в1.619 раза. Эти40% и замедление не
переносятся на реальную7B. Все raw records, telemetry/GEMM, CUDA witnesses,
source hashes и независимые CPU audits — в [архиве](D1_EVIDENCE.md).

Все D1 VM и контейнеры удалены, частоты сброшены, persistence выключен, временные SSH-ключи
отозваны. Последний снимок D1$9.014/$15; обе попытки проверки качества стоят пока$0.127.
Трафик может доначислиться; резерв$1 сохранён, проверка уложилась в свой лимит$1.50.

Предлагаю принять **ограниченный research-результат** BF16/RTX3090 для указанных
форм и seq128, с [явно открытым остальным покрытием](D1_ACCEPTANCE.md).
Полное закрытие D1/#842 требует решения владельца. Автоматическое включение в
production и перенос результатов на остальные режимы не предлагаются.
