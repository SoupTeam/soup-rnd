# D1 — текст для передачи тимлиду

Передаю D1 на research review: [PR #16](https://github.com/SoupTeam/soup-rnd/pull/16).

Сделан checkpoint-safe fused NF4 forward/dX backend для ограниченного BF16 scope.
Packed weights и scales видимы checkpoint; штатная арифметика cuBLAS сохранена.
Большой recycled-buffer gate и отрицательный контроль проходят. На decoder
hidden4096, четыре слоя, seq128 три полных обновления точно совпали с native
streaming и отдельно с непатченным resident NF4.

**Польза для Soup:** на этом полном streaming-шаге peak allocated уменьшился
на **157 MiB**, reserved — на **140 MiB**. Это синтетический shape fixture;
числа не переносятся автоматически на 7B/8B.

**Ускорение не заявляю:** полный ABBA-блок отклонён из-за частот, продолжение
остановлено по правилу. Маленькие ранние пилоты не считаю доказательством ускорения.
Production автоматически не переключён; полная приёмка D1/F1 остаётся неполной.

Приложены [итоговый отчёт](d1-final-result-20261016.md),
[архив исходных измерений с проверкой целостности](D1_EVIDENCE.md), raw CUDA tensors,
source SHA, команды, версии, GEMM ceiling, телеметрия и независимый CPU replay.
12 GPU-регрессий прошли; локально 132 passed / 13 hardware skips, Ruff чистый.
Все аренды удалены, расходы по снимку $8.354 из $10.

Предлагаемый статус карточки: **«На проверке — research result»**.
В «Готово» переводит проверяющий после решения по ограниченному scope и
открытому perf-критерию. Это передача результата, а не заявление, что все
критерии полного production D1 пройдены.
