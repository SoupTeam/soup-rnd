# PR #72: правило решения для F1-сравнения sync и «всё вместе»

Написано 2026-11-19 до первого запуска F1-блоков. Метод: `benchmarks/METHOD.md`.
Драйвер: `benchmarks/harness/p72_f1_blocks.py`.

## Вопрос

Быстрее ли шаг MBR на Moonlight-16B-A3B (окно 8 x 64 токена, группа MBR 8), если вместо
`--expert-transfer sync` включить `packed`, предзагрузку эксперта и хост-кеш 12 ГиБ?

- Вариант A: `--expert-transfer sync`.
- Вариант B: `--expert-transfer packed --expert-prefetch --expert-host-cache-mib 12288`.
- Запуск: свежий процесс моста с `--phase-profile-only --profile-kinds mbr
  --phase-profile-blocks 0 --timed-steps 3`. Число запуска это медиана трёх шагов после
  разогрева. Первый (холодный) шаг пишется отдельно и в сравнение не входит.
- Порядок A, B, B, A. Пилот 5 блоков, затем по `blocks_to_add`, не более 10 блоков.

## Проверки достоверности

| строка | проверка | обязательна | если не выполнена |
|---|---|---|---|
| `suspend` ok на каждом запуске, который читает вердикт | `suspend` | да | нет вердикта |
| `power` ok на каждом запуске, который читает вердикт | `power` | да | нет вердикта |
| `foreign_reads` | `foreign_reads` | нет | см. ниже |

`foreign_reads` исключён из обязательных. Причина: на контейнере vast.ai каталог кеша не
сопоставляется с блочным устройством, проверка всегда `unknown` (проверено на хосте
2026-11-19: «maps to no block device»). Чтения соседей по хосту этим прогоном не видны, и
вывод нужно читать с этой оговоркой. Void по любой проверке всё равно исключает запуск.

Запись частоты GPU (`gpu_clock`) читается вручную по каждому запуску. Запуск с медианной
частотой SM заметно ниже остальных или с `sw_power_cap` и `sw_thermal_slowdown` почти во всех
отсчётах не используется, блок заменяется.

## Строки вердикта

1. Эквивалентность: контрольная сумма градиентов (`grad_sha256`) одинакова во всех запусках
   обоих вариантов. Иначе вердикт «числа различаются», скорость не оценивается.
2. Эффект: парный t-тест по разностям блоков (среднее B минус среднее A), двусторонний, 5%.
   B быстрее A, если тест значим и средняя относительная разность меньше нуля.
3. Практический порог: B считается ускорением, только если средняя разность не менее 10%
   (по модулю). Меньший значимый эффект записывается как «значим, но меньше порога».

## Границы вывода

- Одна модель (Moonlight), одна карта (RTX 3060 12 ГБ), один хост, одно фиксированное окно.
- Хост-кеш вмещает весь набор экспертов (9,3 ГБ при бюджете 12 ГиБ). Для моделей, где он их
  не вмещает, результат не переносится.
- Хост-кеш заполняется на разогревочном шаге, поэтому измерение идёт на заполненном кеше.
