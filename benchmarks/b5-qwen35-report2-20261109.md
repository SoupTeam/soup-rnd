# B5, отчёт 2: Qwen3.5-35B-A3B на RAM tier при лимите 32 GiB не помещается — реальная модель

Подпись отчёта: реальная модель. Реальные и синтетические результаты в одном отчёте не смешиваются.

Этот отчёт фиксирует отказ до запуска. Обучение не проводилось, аренды не было, журнала для судьи `b5_judge.py` нет. Все размеры ниже получены из заголовков safetensors реальной модели и из функций Soup. Это расчёт, а не измерение с хоста.

## Итог — реальная модель

**Что показала проверка — реальная модель**

| Вопрос | Ответ |
| --- | --- |
| Помещается ли NF4-кеш Qwen3.5-35B-A3B в RAM tier при лимите 32 GiB | Нет. Кеш около 67.3 GB (расчёт по заголовкам), потолок RAM tier Soup при 32 GiB равен 18.9 GB |
| Совпадает ли это с картой B5 («NF4-кеш около 19 GB») | Нет. 19 GB это грубая оценка Soup, которая считает NF4 для всех параметров. Слитые эксперты при NF4 остаются в bf16 |
| Помещался бы кеш, если бы эксперты были в NF4 | Тоже нет. Около 21 GB вместе с резидентными добавками при потолке 18.9 GB |
| Нужен ли повтор поверх проверки из PR #426 | Нужен, но не на этом уровне и не при этом лимите. Решение записано в тикете 04 |
| Что измерено на железе | Ничего. Пик RAM, пик VRAM, скорость, градиенты и обновление адаптеров не измерены, потому что запуска не было |

Правило тикета 04: если кеш не помещается, это результат, а не повод расширять лимит. Лимит не менялся. Что делать дальше, решает пользователь.

## Размер кеша — реальная модель

**Кеш NF4 по классам тензоров (расчёт по заголовкам) — реальная модель**

| Класс | Байт в кеше |
| --- | --- |
| Маршрутизируемые эксперты, bf16 (32 212 254 720 параметров) | 64 424 509 440 |
| Плотные линейные слои в NF4 (13 суффиксов: внимание, `linear_attn`, общий эксперт) | 792 622 080 |
| Остальное в слоях, bf16 | 44 258 560 |
| Эмбеддинг, `lm_head`, нормы (резидентные добавки) | 2 034 241 536 |
| Итого | 67 295 631 616 |
| Для сравнения: если бы эксперты были в NF4 | 20 990 515 456 |
| Для сравнения: грубая оценка Soup, одинарная квантизация | 20 222 965 692 |
| Для сравнения: грубая оценка Soup, двойная квантизация | 18 546 495 879 |

Причина разницы. Скелет NF4 заменяет только `nn.Linear`. Слитые эксперты это 3D-параметры `Parameter` в bf16, и `quantised_layer_suffixes` их не возвращает. Опция `moe_expert_quant` при `stream_layers` отказывает (`schema.py:6738`), включить NF4 для экспертов в этой ветке нельзя. NF4 считался как 0.5 байта на элемент плюс fp32 absmax на 64 элемента (одинарная квантизация), как в расчёте Moonlight. Для Moonlight такой расчёт дал 9.95 GB, измерено 9.95 GB. Для Qwen3.5 измерения нет.

## Что говорит планировщик Soup при 32 GiB — реальная модель

**Решение `build_stream_plan` при `total_ram_bytes` 34 359 738 368 — реальная модель**

| Вариант | Хранилище слоёв | Диск NVMe | Диск не NVMe | Физической RAM нужно для RAM tier |
| --- | --- | --- | --- | --- |
| Как собрано сейчас, эксперты bf16 | 65.26 GB плюс 2.03 GB добавок | tier=disk | отказ, нужен NVMe или больше RAM | не меньше 122.4 GB |
| Гипотеза, эксперты NF4 | 18.96 GB плюс 2.03 GB добавок | tier=disk | отказ | не меньше 38.2 GB |

Потолок RAM tier это 55% физической RAM (`PHYSICAL_RAM_TIER_HEADROOM`). При 32 GiB он равен 18.90 GB. Вывод скрипта лежит в `evidence/b5-qwen35-20261109/qwen35_tier.out`. Скрипт вызывает `build_stream_plan` и `estimate_stream_store_bytes` напрямую, `soup train` на этой модели не запускался.

## Две находки про Soup — реальная модель

**Что нашлось по пути — реальная модель**

| Находка | Основание | Статус |

Отказ случился бы только после скачивания 72 GB и записи кеша | Подтверждено расчётом, `soup train` не запускался |
| `stream_source: ram` может молча уйти на диск | После шардинга `stream_setup.py:1065` берёт `plan.tier`. `build_stream_plan` не получает `stream_source`, на NVMe возвращает `disk`, а заметка плана советует `ram` как способ отказа | Вывод по чтению кода, поведение не воспроизведено |

Обе находки относятся к `src/`, тикет 04 их не заказывал. Исправлений в этой ветке нет. Вторую нужно проверить тестом до того, как любой отчёт будет полагаться на `stream_source: ram` как на отказ.
